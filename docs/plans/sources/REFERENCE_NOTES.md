# Sources Consulted — Current Context Notes

These sources were consulted while premiumizing the package for current market and platform context. Use official documentation as source of truth before implementation.

## Agentic coding landscape

- GitHub Docs — GitHub Copilot cloud agent: describes Copilot cloud agent researching a repository, planning and making code changes, and creating pull requests for review.
  - https://docs.github.com/en/copilot/how-tos/use-copilot-agents/cloud-agent
  - https://docs.github.com/copilot/concepts/agents/cloud-agent/about-cloud-agent

- Anthropic Claude Code Docs: describes Claude Code as an agentic coding tool that reads codebases, edits files, runs commands, and integrates with developer tools.
  - https://code.claude.com/docs/en/overview
  - https://code.claude.com/docs/en/how-claude-code-works

- OpenAI Codex CLI docs/GitHub: describes Codex CLI as a local coding agent that can read repositories, make edits, and run commands.
  - https://developers.openai.com/codex/cli/features
  - https://github.com/openai/codex
