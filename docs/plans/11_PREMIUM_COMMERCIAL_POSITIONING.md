# 11 — Premium Commercial Positioning

## Product category

```text
Local-first AI engineering governance workbench
```

Do not position VibeForge as:

```text
AI IDE
coding chatbot
autonomous coder
model wrapper
generic agent framework
```

## Premium wedge

VibeForge wins when the buyer cares about:

- local repo control
- evidence-backed AI work
- agent governance
- patch provenance
- review discipline
- cloud privacy boundaries
- developer authority
- team/enterprise trust

## Hero

```text
Govern the code your agents write.
```

Subhead:

```text
VibeForge gives serious developers local-first agentic coding with isolated workcells, board-reviewed patches, provenance receipts, privacy-safe cloud escalation, and developer-authorized promotion.
```

## Proof bullets

```text
No active-tree mutation by default.
No cloud job without payload preview.
No patch promotion without receipt.
No analytics event outside the safe allowlist.
No hidden agent authority.
```

## Product tiers

| Tier | Buyer | Promise |
|---|---|---|
| Local | privacy-first solo developer | local scan, local receipts, local board MVP |
| Pro | serious daily AI coding user | cloud-approved deep review, BYOK, budget caps |
| Power | heavy agentic user | fleet modes, higher limits, overnight reviews |
| Team | small engineering team | shared policy, pooled credits, PR summaries |
| Enterprise | regulated org/platform group | private cloud/on-prem route, SSO/RBAC, custom telemetry, SIEM roadmap |

## Competitive differentiation

| Competitor type | Their center of gravity | VibeForge differentiation |
|---|---|---|
| Cloud coding agents | remote task execution and PR generation | local-first governance and evidence around cloud execution |
| Terminal agents | fast agentic edits and command execution | permission envelopes, receipts, board review, vault |
| AI IDEs | in-editor productivity | cross-tool governance, provenance, and auditability |
| DevSecOps tools | scanning and policy | agentic workflow control before code is promoted |

## Demo storyline

1. Open repo dashboard.
2. Show Local Lock mode.
3. Ask VibeForge to review an auth change.
4. Show context preview and excluded secrets.
5. Run isolated workcell.
6. Show patch candidate, tests, and board cards.
7. Show material disagreement between security and product reviewers.
8. Approve with modification.
9. Show VibePatch Receipt.
10. Export PR package.
11. Show Cloud Approval Mode as optional deep review.

```text
SLSA certified
SOC 2 compliant
zero-risk
autonomous production-ready merge
complete privacy guarantee without configuration
```

Say:

```text
SLSA-aligned receipts
privacy-first architecture
approval-gated cloud escalation
```
